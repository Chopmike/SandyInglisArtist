Image Upload Guidelines

📐 Dimensions

For best results, images should be at least 1200px on the longest side. The gallery uses responsive sizing, so all orientations (landscape, portrait, square) are supported without cropping.

📁 File Format

Accepted formats: JPG, PNG, WEBP. WEBP is recommended for best performance and quality balance.

💾 File Size

Keep files under 2MB for optimal loading times. Use image compression tools if needed.

🎨 Quality

Use high-quality images with good lighting and sharp focus. Images will be displayed in a professional gallery layout.

Note: After uploading artworks, you'll need to commit and push the changes to your GitHub repository for them to appear on the live website. The artworks are stored in data/artworks.json and images in images/artworks/.
